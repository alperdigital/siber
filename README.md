# Abdullah Alper BAŞ · Yazılım portföyü

İzmir’de bağımsız çalışan bilgisayar mühendisi Abdullah Alper BAŞ’ın web uygulamaları, iş otomasyonu ve mobil prototip portföyü. Sitede küçük işletmeler için etkileşimli bir talep takip panosu, klinik web sitesi örneği ve Türkçe sosyal medya rehberi bulunur.

- [Portföyü inceleyin](https://alperdigital.github.io/siber/#portfoy)
- [Talep takip panosunu deneyin](https://alperdigital.github.io/siber/demo/)
- [Bir proje için iletişime geçin](https://alperdigital.github.io/siber/#teklif)

GitHub Pages, siteyi [portfoy dalının kök dizininden](https://github.com/alperdigital/siber/tree/portfoy) yayımlar. Kaynak dosyalar ve yerel çalıştırma yönergesi o daldadır.
